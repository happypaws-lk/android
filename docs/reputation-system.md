# HappyPaws Reputation System

## Overview
The HappyPaws Reputation System is designed to build trust within the community. Users earn reputation points and trust badges by performing verified actions that contribute to the platform's goals of animal rescue, rehoming, and community support.

## Point Allocation
Users earn reputation points for the following actions:

| Action | Points | Description |
|---|---|---|
| **Account Verification (KYC)** | +20 | Successfully verifying identity via national ID or passport. |
| **Adoption Application Accepted** | +50 | Successfully completing the adoption process for a listed animal. |
| **Completing a Transport Task** | +30 | Successfully picking up and dropping off an animal as requested. |
| **Creating an Adoption Listing** | +15 | Posting a verified adoption listing for rehoming an animal. |
| **Creating a Rescue Report** | +10 | Reporting a stray or injured animal that is triaged and confirmed. |
| **Creating a Community Story** | +2 | Sharing an update, success story, or advice on the Community tab. |
| **Receiving an Upvote** | +1 | Receiving an upvote on any of the 4 community post types. |
| **Giving an Upvote** | 0 | No points are awarded for giving an upvote to prevent point farming. |

## Reputation and The Community Tab
The Community Tab integrates directly with the Reputation System.
- **Top Posts:** Posts can be sorted by "Top - Daily", "Top - Monthly", "Top - Yearly", and "Top - All Time", which is calculated based on the total upvotes a post has received.
- **Author Trust:** An author's total reputation points are often displayed next to their name on their posts to indicate their reliability and history on the platform.

## Future Enhancements
- **Trust Badges:** Automatic assignment of badges (e.g., "Top Foster", "Verified Transporter") when specific point thresholds in categories are reached.
- **Moderation:** Points can be deducted by Administrators if a user violates platform rules or has a dispute ruled against them.
